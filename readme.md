# 🎬 MovieApp

A mobile application developed in **Kotlin** for Android, designed to display movie information through a clean and modern interface. Based on Gastón Saillén's course - [Curso definitivo para aprender a programar en Android](https://www.udemy.com/course/curso-definitivo-para-aprender-a-programar-en-android/?couponCode=25BBPMXPLOYTRMT)

## 📱 Features

- List of popular movies.
- Detailed view for each movie.
- Modern UI following Android best practices.
- MVVM-based architecture.

## 🛠️ Technologies Used

- **Kotlin**
- **Android SDK**
- **Retrofit** (for API consumption -> [TheMovieDB](https://developer.themoviedb.org/)
- **ViewModel**
- **LiveData**
- **Glide** (for image loading)
- **Gradle**
